# HR Attrition Analysis | SQL & Power BI

## Project Overview
This project analyzes employee attrition to identify workforce patterns and high-risk employee segments using SQL and Power BI.

## Business Objectives
- Measure overall employee attrition.
- Compare attrition across departments and job roles.
- Analyze the relationship between overtime and attrition.
- Identify employee segments with higher observed attrition.

## Tools Used
- SQL
- Microsoft Power BI
- Excel (if used for data preparation)

## Key Findings
- Overall attrition: 16.12% (237 out of 1,470 employees).
- Sales department attrition: 20.63%.
- Sales Representatives attrition: 39.76%.
- Attrition among employees working overtime: 30.5%, compared with 10.4% among other employees.
- A segment combining overtime, low satisfaction, and poor work-life balance showed 41.03% attrition.

## Business Recommendations
- Investigate retention challenges in high-attrition roles.
- Review overtime practices and employee workload.
- Monitor satisfaction and work-life balance indicators.
- Use periodic attrition reporting to track changes over time.

## Disclaimer
These findings show observed associations and do not establish causation.
